# Expense Tracker Web App

A lightweight, interactive web application built with Python and Streamlit to help users analyze and visualize personal expenses from CSV uploads.

## Features
- **CSV Data Ingestion:** Upload and preview raw expense datasets instantly.
- **Automated Aggregation:** Uses Pandas to group spending data and calculate total expenses per category.
- **Data Visualization:** Renders dynamic bar charts to break down financial habits at a glance.

## Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data Manipulation:** Pandas
